# 调理规则映射表

> 用途：daojia-wuxing-huajie 报告主控技能在**确定调理顺序、化解冲突规则**时使用。
> 核心：把总纲的「通关泄秀优先」转成**有条件的决策流程**，不硬编码成万能排序；每条建议都要回看是否会加重其他失衡。

## 一、病灶 → 方向映射（先定矛盾，再选法）

| 命局证据 / 主要矛盾 | 调理方向 | 关键约束 |
|--------------------|----------|----------|
| 两股力量对峙（相冲/相战），且有适合的中间五行 | 通关（中间五行调和） | 通关五行若本身是忌神，须权衡；否则不强行通关 |
| 忌神过旺、无制 | 优先泄化（旺行所生之行）；极偏激才用克 | 泄法更温和长效，克法仅宜极端，慎用 |
| 喜用偏弱或受克 | 扶助（补益喜用） | 缺/弱且为喜用才补；忌神缺位反为吉 |
| 流通阻滞、五行不流转 | 疏通通关 | 先解郁结，勿直接补泄 |
| 身弱但某行过旺为忌 | 先制强（泄/制忌神），后扶弱 | 次序不可颠倒（先制强、后扶弱） |
| 从格 / 专旺 / 格型临界 | 降级为「需谨慎判断」 | 常规补泄不适用，不强行给单一答案 |

## 二、调理顺序决策流程（条件分支，非固定排序）

请按下列分支逐步判断，**每步之后回看**：

1. **无对冲、无流通阻滞** → 直接判旺衰喜忌，选泄/补/克。
2. **有对冲相战** → 先看是否有适合的中间五行可通关；
   - 中间五行为喜用或中性 → 通关优先；
   - 中间五行本身是忌神 → 指出权衡与不确定性，不硬通关（此时可改选用阻力更小的手段，或标注「无法两全」）。
3. **忌神过旺** → 判断适不宜泄化：能泄则泄；属极端偏激、须制约的本命行才考虑克制。
4. **喜用偏弱/受克** → 评估扶助；但若扶助会加重忌神，先处理忌神。
5. **通关、补、泄、制互相牵制** → 停止给出「看似精确、实际无依据」的强制方案，转为列明取舍与重判从整体格局选主矛。
6. **任何补/泄/通关方案** → 最后统一回看：是否加重另一失衡？若会，说明取舍并降其优先级。

## 三、补 / 泄 / 通关具体做法（对照物象·方位·行为）

| 方向 | 方法 | 要点 |
|------|------|------|
| 通关·水火取木 / 金木取水 / 土水取火 | 按传统「通关原理」 | 两行间加中间五行调和，化克为生 |
| 泄旺 | 旺者泄秀（金旺以水、水旺以木、木旺以火、火旺以土、土旺以金） | 用旺行所生之行疏导；慎用克法 |
| 补益（金/木/水/火/土为喜用而弱/缺） | 对应补金/木/水/火/土之法（方位·色彩·饮食·物象·行为） | 只在「缺/弱且为喜用」时补，忌过补 |
| 先疏土后养木 | 木弱多因土旺克木 | 先清淡疏土，再养木，否则木被旺土克制 |

## 四、冲突处理总则（复用总纲 + 内部张力整理）

| 冲突源 | 本次如何兼容 |
|--------|--------------|
| 「相冲优先通关」vs「通关泄秀优先」 | 皆成立且不矛盾：有对冲先通关，其后主流程仍按「通关泄秀→补益→克制」；两者是不同层级（先解对冲、再定普通过旺处置） |
| 「喜忌须全盘综合」vs「实操过三关首关即按旺衰定喜忌」 | 如实保留该内部张力；以「旺衰＋十神」为主轴，单一条件边界模糊时（甲木春生、从格临界）明示不确定性，不强行定喜忌 |
| 通关五行是忌神 | 指出权衡，给出「通关 vs 不加重忌神」的取舍，不伪装精确 |
| 补泄制互相牵制 | 从整体格局取主矛，次要项降级，报告说明为什么舍弃/降低优先级 |
| 神煞疑凶 vs 五行主方案冲突 | 以整体命局判断为准，神煞项降级或作「不制造恐慌」的提示 |

## 五、三层方案优先级映射

| 层 | 内容 | 优先级规则 |
|----|------|-----------|
| 命局关键五行 | 主要矛盾 + 补/泄/通关的选择依据 | 最高；先定主矛 |
| 行为与环境建议 | 低成本、可选择、不过度承诺的日常做法（颜色/材质/方位/饮食为传统文化辅助，不替代健康财务职业决策） | 次之；可选项 |
| 神煞应对 | 依据较弱的项只作「不制造恐慌」的提醒；仪式/饰品/摆件做法注明口径与非保证性 | 最低；不得用「必须购买/不做就有灾」 |
