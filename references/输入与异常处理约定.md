# 输入信息与异常处理约定

> 用途：daojia-wuxing-huajie 报告主控技能在**开头校验输入、识别资料不足**时使用。
> 原则：先核对、再判断。无法核对或明显冲突时，宁可降级、不硬断。

## 一、最低输入清单与格式约定

| 字段 | 是否必填 | 格式约定 |
|------|----------|----------|
| 年柱 | 必填 | 十天干（甲…癸）+ 十二地支（子…亥），如「丙午」；不合法的干支组合记为「非法」 |
| 月柱 | 必填 | 同上；须与季节气候一致（见误差异常） |
| 日柱 | 必填 | 同上；日柱天干即日主，是喜忌判定的主轴 |
| 时柱 | 必填 | 同上 |
| 性别 | 必填 | 男 / 女（涉及神煞柱位口径与部分格局用词） |
| 出生年份 | 至少选填 | 用于与年柱核对（见下）。**口径必须说明**：被当作公历年还是农历年/属相年，由用户给定时定，技能不自作主张换算 |
| 起运年龄 | 至少选填 | 直接采用户给定的年龄数字；技能不自行推算精确起运日期、不擅自换算成公历起点 |

> 若用户只给五行统计（如「金木水火土各几个」）而无四柱，视为信息不足，走缺项处理。

## 二、输入校验步骤（顺序执行，校验不过即停）

1. **逐柱格式检查**：四柱每柱是否「一个天干 + 一个地支」，干支是否都在合法表内。
2. **天干地支相配校验**：十天干与十二地支按甲子顺序相配，天干必须落在地支的「有效配对」上（如甲戌可、甲酉不可——酉是辛阴支，甲阳干不可配）。校验不准则标注异常。
3. **出生年份 ↔ 年柱核对**：用户给的出生年份（按既定口径）应能推出对应的年柱；推出结果与用户所给年柱不一致时，标注冲突。
4. **月柱 ↔ 季节气候核对**：月柱地支与四季基本对应（寅卯辰春、巳午未夏、申酉戌秋、亥子丑冬）；明显错位时提示，但不据此推翻用户排盘，只作一致性提示。
5. **起运年龄口径确认**：以用户提供的「起运年龄」数值直接采用，不做精确化。
6. **神煞查法所需基准确认**：确认年支、日干可用（神煞查法表以年支、日干为基准）。

## 三、异常分级与处置

| 异常 | 处置 | 是否继续输出 |
|------|------|--------------|
| 四柱格式非法 / 缺柱缺失 | 明确指出缺项或不合法项 | 否（不输出确定喜忌/神煞/调理结论） |
| 出生年份与年柱冲突 | 指出冲突，请用户复核；无法解决则缺项处理 | 否，除非用户明确其年柱为准 |
| 用户只给五行统计、无四柱 | 指出缺四柱，无法判喜忌/神煞 | 否（可给「五行结构观察」但明确属初步、非结论） |
| 起运年龄 / 出生年份含糊 | 直接采用可行部分，其余列为「未给出」 | 部分（只给已确认项的判断） |
| 神煞查法无明确规则 / 流派口径不一致 | 标注「未判定」，补造规则 | 该单项列为「未判定」，其余继续 |

## 四、信息不足时的有限初步分析口径

当四柱可用但部分字段缺失或不一致时，可输出**以「初步/提示」标注**的内容，并逐项注明哪些暂不能判断：

- 可给：四柱明干、地支藏干、日主五行、月份气候这类纯结构信息。
- 不可给：确定的喜用忌神、确定的旺衰结论、确定的贴身神煞吉凶、确定的调理方向。
- 输出时开头显式写「以下为初步观察，非最终结论；需补足 XX 后复核」。

## 五、不硬断的边界情形

复用 daojia-zonggang 与五行判定检查表，下列情形一律降级为「需谨慎判断」，不强行给单一答案：

- 存在从格（从强/从弱/专旺等）或格型临界，常规旺衰与喜忌方向不成立。
- 不同判断路线会导向相反补泄方案（如身弱喜印 vs 印旺懒散）。
- 通关所需五行本身是忌神，补泄制互相牵制。
- 全书无四柱、口径不清，无法独立复核的个案。

> 上述情形下，报告明确保留分歧、指出权衡与不确定性，不以「精确方案」伪装覆盖。
