# 五行力量判定检查表

> 用途：daojia-wuxing-huajie 报告主控技能在**判定某五行旺衰、是否过旺/偏弱/缺位**时逐步核对。
> 核心：先辨结构（月令/通根/透干/藏干/生扶克泄/合冲刑会），再综合判断；**不把「干支组数」「五行数量」当结论**。

## 一、判定顺序（逐行核对，勿跳跃）

对金木水火土每一行，按下述顺序逐项核对，再综合：

1. **月令**（得令/失令/得月令之助）：该行是否当令？月支生我、比助我者得令。
2. **通根**（得地）：该行天干在地支是否有本气根？根在月令/日支/时支/年支，强根（本气）>中气>余气。
3. **透干**（该行天干是否明透）：明干根力强于藏干。
4. **藏干**（地支中的该行之气）：即便不透，根深亦可成力量。
5. **生扶**（印比）：谁生我、谁比我（帮扶的力量）。
6. **克泄耗**（官杀克、食伤泄、财耗）：谁克我、我生谁、我克谁（消耗的力量）。
7. **合冲刑会**：地支六合、三合、三会、六冲、三刑对力量的加强与破坏。

## 二、力量评估维度表

| 维度 | 提问 | 判断要点 |
|------|------|----------|
| 月令当令 | 此五行是否值月令旺气？ | 当令偏旺；失令偏柔（先记，勿单凭此定结论） |
| 得地通根 | 天干在地支有没有本气/中气根？ | 根多根强则力量足 |
| 透干 | 该行天干是否明显透出？ | 明透比藏干更有"政治家/事业"表现力 |
| 藏干汇聚 | 地支藏干是否汇聚该行之多气？ | 藏而不透，力量仍在 |
| 生扶 | 印星比劫是否帮扶？ | 帮扶越多越旺 |
| 克泄耗 | 官杀/食伤/财是否消耗？ | 受克泄耗越多越被削弱 |
| 合会 | 三合/三会/六合是否增其力 | 合会增强 |
| 刑冲破损 | 六冲三刑是否损其根 | 冲刑可能伤根、或激发（视具体） |

## 三、综合归类（判定用「偏旺/偏弱/缺位/受阻/相对平衡」）

| 状态 | 判定依据（须综合，非单一） | 处理倾向 |
|------|---------------------------|----------|
| 偏旺 | 得令＋得地＋得生扶，且克泄耗不足以平衡 | 过旺为忌则泄/制；为喜则不必强行削弱 |
| 偏弱 | 失令/根浅/被克泄耗重，帮扶不足 | 为喜用则扶补；为忌则不强补 |
| 缺位 | 四柱明干与地支藏干均无该行本气 | 结构观察；是否需补须看喜忌，非缺即补 |
| 受阻 | 该行有根有气但被冲、刑、合绊、墓库束缚 | 先解阻滞（通关/疏通），非直接补泄 |
| 相对平衡 | 生扶与克泄耗大致均衡 | 少动少调，避免过补过泄 |

> **铁律**：状态描述（偏旺/缺位…）与操作建议（补/泄/通关…）是**两件事**。
> 「缺位」只是结构观察；只有当该缺位之行为命局所需（喜用）时，才进入补益建议。忌神缺位反为吉，不可补。

## 四、防误判清单（常见错误 → 正确做法）

| 常见误判 | 正确做法 |
|----------|----------|
| 「某行干支≥3组 → 过旺」 | 计数只是线索；须看是否得令、得地、透干，以及克泄耗是否平衡。数量多但失令无根受制，未必过旺 |
| 「缺某五行 → 需补某五行」 | 缺的若是忌神反为吉、不补；只有缺/弱且为喜用才补 |
| 「身弱 → 一味扶身」 | 身弱但某行过旺为忌时，应先制强（泄/制忌神），后扶弱；次序不可机械 |
| 「季节 → 定喜忌」 | 季节旺衰只是第一步；被克泄过度、从格/专旺、漂木无根等情况喜忌相反，须全盘复核 |
| 「单一神煞 / 单一维度 → 定吉凶」 | 喜忌须全盘综合（旺衰+十神+刑冲合害+流通），不能单点定论 |

## 五、特殊格局处理

- **从格/专旺（从强从弱、曲直/炎上等）**：常规身强身弱判定不成立，喜忌方向反转。标记「需谨慎判断」，不套用常规补泄，不强行给单一答案。
- **甲木春生之类「得令却需帮扶」**：得月令不等于必旺；面无根、被克泄过度者反需帮扶，喜忌与原判断相反。须全盘复核后再定。
