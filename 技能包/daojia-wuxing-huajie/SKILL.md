## 核心判断

五行失衡不是一句"缺什么补什么"，而要分四态对待：过旺要泄、偏弱缺失（且为喜用）才补、相冲相战先通关、流通阻滞要疏通；日常普通人的失衡优先用泄法、慎用克法，所有调理都怕"过"——过补、过泄、过制都会造出新的失衡。

## 断法步骤

1. **辨识五行四态**：清点四柱干支，数每行出现的组数、是否得月令/得地/得生助，先分出"过旺 / 偏弱缺失 / 相冲相战 / 流通阻滞"是哪一类（复合型最常见，可多类同现）。识别有优先级：先看有无干支相冲（先解气场郁结），再看旺衰，最后才判喜忌。[L4>五行失衡识别；L3>五行生克·冲合刑害表]
2. **判喜忌、定补泄方向**：承接 daojia-zonggang 得出的用神/忌神，判定该行是喜用还是忌神——过旺忌神要泄（或极偏激时克），偏弱缺失的**喜用**才补，忌神缺失反为吉、不补。[L5>病药 / 喜神用神 / 忌神凶神]
3. **按五行选补法 / 泄法 / 通关**：补——照补金/木/水/火/土之法（物象·方位·色彩·饮食·行为）；泄——照"旺者宜泄，强者宜疏"，用旺行所生之行疏导（金旺以水泄、水旺以木泄、木旺以火泄、火旺以土泄、土旺以金泄）；相冲——按通关原理在两行之间加中间五行（水火取木、金木取水、土水取火）。次序：**通关泄秀优先 → 补益弱势 → 克制制衡**。[L4>补X之法 / 五行泄法；L5>通关 / 五行平衡]
4. **配合物象、方位、行为、心性**：落到颜色材质、居住/办公/出行方位、饮食作息、行为习惯与心性修养上，环境—穿戴—饮食—行为—心性必须同步调整、内外结合，并长期坚持。[L4>化解方法分类总览；L8>健康疾病（五行—脏腑）]

## 判断标准

断对了会看到：不同五行短板对应到不同的人生板块（缺火人缘淡、缺金决断差、缺木拖延、缺水思维差、缺土根基浮），且症状能与"该行过旺则克其所胜"对上（如金旺者肝胆/呼吸道弱）；方案里能清晰区分"该补、该泄、该通关"，不会一律补。

断错了会看到：把"缺什么"直接当"补什么"（缺忌神也去补），或对过旺之行硬用克法、对相冲之行直接补泄；结果命主越调越乱、心态更差——这正是书里反复警告的"盲目补五行反而运势更乱"。

## 什么时候不该用它

- **判不出喜忌就不可用**：本技能的地基是喜忌。没有出生时间、无法排八字，或喜忌未定（未过 daojia-zonggang）时，全流程不能启动。
- **缺的是忌神，不必补也不该补**：所缺/偏弱的五行若是忌神，反为吉，补之有害；只有喜用才补。凡"看到字面缺某行就想补"的用法一律不成立。
- **相冲相战不可直接补泄**：命局有对冲干支时，须先通关调和；跳过通关直接补或泄，会加重对峙。
- **泄法/克法不辨则误用**：普通过旺应优先泄、慎用克；把克法当万能解，或泄得过度，都会造出新失衡。
