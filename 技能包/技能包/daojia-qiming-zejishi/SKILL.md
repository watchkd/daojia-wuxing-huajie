# 起名改名与择吉开光

## 什么时候用它

用户在**起名 / 择日 / 开光 / 摆件**上要动手时用它：

- 「孩子起名要补什么五行 / 用哪些字根」「这名字好不好、要不要改名」
- 「改名到底有用吗 / 我改过一次还能再改吗」
- 「结婚日子怎么选 / 开业、搬家、签约哪天好」「剖腹产给孩子挑个生辰」
- 「买的摆件要不要开光 / 开光有什么讲究」「家里摆什么能催运助势」

**它是 daojia-zonggang 的下游专项技能：本技能的一切选字、择日都建立在喜忌之上**——起名用字补益须先定喜用五行；不先判喜忌，选字会补错五行、择日会冲了本命。所以必须**先过 `daojia-zonggang` 判喜忌、定位命局病灶**，再进本技能。纯论财运、婚姻、灾祸、健康的病因拆解不要用它，走对应领域技能。

## 核心判断

- 起名不是挑好听的字，也不是"缺什么补什么"；**先定喜忌、再按「弱什么、需要什么才补什么」选字**——缺的若是忌神，补齐反而加重命格隐患、压制用神。
- 择吉不看通用黄历吉凶，**第一优先是本命适配**：所选时日不可冲、刑、害自身年命与日主；他人大吉之日，可能正是你的岁破、日冲之日。
- 开光器物护主催运全凭主人心性与德行；**只摆物件、不修心行善，再贵的摆件、再灵的开光也留不住福、挡不住灾**。

## 断法步骤

1. **过 daojia-zonggang 定旺衰、立喜忌**：看日主强弱定喜用五行与忌神五行，这是选字、择日、择时的唯一依据。 [L5 > 喜用忌凶；L4 > 起名改名的八字依据]
2. **定起名补益方向**：身旺用泄、克、耗的五行文字疏解过旺、收敛心性；身弱用生、扶、助的文字增补气场、稳固福气。 [L4 > 起名改名的八字依据；L3 五行 > 旺衰]
3. **按命格类型定用字**：分四类——身弱（柔和绵长字，忌过刚过烈）、身旺（泄旺/制盛/通局之字）、寒湿（火行暖字、木行生发字，忌金水寒凉）、燥热（水行润字、金行清字，忌木火燥热）。 [L4 > 姓名用字的五行补益；L3 五行 > 调候]
4. **逐字定五行并匹配强弱**：按字义→字形（偏旁）→字源→气场综合判，字义优先；同一五行字分强/柔，按命格急缓选用，该行过旺为忌者忌用强重字。 [L4 > 姓名用字的五行补益]
5. **排禁用字**：生僻/异体字、衰败杀伐寒凉义字、霸烈狂戾锋等戾气字、以及普通命格用天地乾坤至尊等极宏大字，一律剔除。 [L4 > 起名改名的八字依据]
6. **改名分级**：先评估原名凶煞程度——无重煞者微调用字、补益五行即可；带重煞、严重失衡者才彻底更名；且一次定局、长期使用，忌频繁更换。 [L4 > 起名改名的八字依据]
7. **重大日子择吉**：先本命适配（不冲不刑不害年命与日主）→再选值日吉神（黄道/建星）→再配吉时；随后二次排查岁破日冲、四离四绝、劫煞灾煞月破、空亡。 [L4 > 重大日子的择吉；L6 > 冲煞/刑煞/害煞]
8. **生宝宝择吉选日**：第一优先级避命格硬伤（四柱严重刑冲害、五行极端失衡、凶煞叠临无贵人、四离四绝）→第二优先级优选上等格局（得令有根、五行流通、吉神贴身、十神纯正）→定时辰（避时辰冲日/刑月/害年并按调候配时）→复查与父母命格不严重相冲。 [L4 > 生宝宝择吉选日；L3 五行 > 旺衰/调候]
9. **开光**：择吉日吉时（成/开/除日，清晨阳气旺）＋净场净物净身净心；按器物类型定重点，守"不可逆、忌污秽、忌重复开光、破损即弃"四忌。 [L4 > 开光流程]
10. **摆件催运**：按需求（招财/镇煞/贵人事业/姻缘和合）选对应摆件，按类别定方位，对症不堆砌、保持洁净、位置固定不挪动。 [L4 > 风水摆件的催运助势]

## 判断标准

- 断对了会看到：起名按喜忌选字后，长期使用命主性格趋稳、人缘贵人渐显（姓名属长期滋养）；择吉选到本命适配的吉日，事后少波折、少反复、少意外；摆件对症摆放、洁净固定后气场顺、所催之事渐有起色。
- 断错了会看到：按"缺什么补什么"选字，补的正是忌神，越用越失衡、性格更偏激；只看通用黄历挑"吉日"，恰逢自身岁破、日冲、四离四绝，事情办不成或事后生变；摆件盲目堆砌、频繁挪动、任其积灰，催运无效甚至反向加剧。

## 什么时候不该用它

- **排不出八字 / 无出生时间者**：选字补益、择日择时、判断开光吉时都以"先定喜忌"为前提，无盘则无从下手。
- **只想"挑个好听的名字""按黄历选个吉日"、拒绝先判喜忌者**：作者明确反对"只看字音字形、机械补齐五行数量""只看通用黄历吉凶"，本技能不配合这种用法。
- **八字已成从强 / 从弱 / 专旺等特殊格局者**：常规身强身弱的用字方向与喜忌不成立，须先按特殊格局单独处理，否则补益方向必错。
- **期待靠改名 / 开光 / 摆件"一夜改运、彻底消灾"者**：姓名属长期滋养型、见效慢，无法快速化解短期灾祸与紧急运势；开光摆件也只能减灾助势，不能逆天改命。
- **只想要物象操作、不愿修心性行为者**：作者反复强调，只摆放佩戴、不修心行善，化解无效甚至反向加剧。
- **纯断财运 / 婚姻 / 灾祸 / 健康的病灶成因**：走对应领域技能（`daojia-caiyun-huajie` / `daojia-shensha-huasha` 等），本技能只管起名、择吉、开光、摆件催运四类操作。
- **需精确到具体干支组合的判语时**：本书案例无四柱，无法给出可被第三方复现的具体判语，只能给方向与规范。
