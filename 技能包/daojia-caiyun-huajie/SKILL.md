## 核心判断

财运不好不是一种病，是六种病，先归类再下药，乱摆招财摆件只会越调越漏。**财库须"先认财、再认库"**——见辰戌丑未就断财库是错的，只有"有财能入库"才算真财库。**禄神是正财福气库**，普通人一辈子的钱来自正财俸禄，正财不稳先养禄。化解没有万能公式，多重漏洞必须多维搭配。

## 断法步骤

1. **辨类型**：先定财运低迷属六大类中哪一类（比劫夺财 / 身弱不担财 / 财库虚空 / 财星受制 / 食伤不通 / 官杀耗财） [L8断事>财运 · L4>财运化解>财运低迷的八字特征]
2. **定根源**：找出漏财通道——是"被分走"（比劫）、"担不住"（身弱）、"无库存"（财库虚空）、"源头断"（财星受制）、"无财可生"（食伤不通），还是"被耗掉"（官杀耗财） [L4>财运化解>财运低迷的八字特征 · L1>地支>财库判定 · L5>病药]
3. **选化解**：对症下单一法——补库守财（补财库）/ 固本养运（禄神旺财法） / 布阵拓渠（四方聚财阵·九宫纳财阵）/ 饰品调五行（珠宝首饰）/ 通气回款（讨债阵） [L4>财运化解>补财库·旺财阵·禄神旺财法·珠宝首饰·讨债阵]
4. **配心性行为**：无论哪种化解，必须配行为收敛与心性调整（戒乱花、减无效借贷合伙、踏实做事），边补边破财者无效 [L4>化解总纲>化解的本质 · L4>财运化解各法]
5. **看大运流年**：查大运流年是否引动原局漏财组合（比劫逢比劫岁运→合伙破财；禄神逢冲→正财动荡），定应期与加固 [L7>大运流年引动]

## 规则集

### L8 断事 > 财运 > 财运低迷六大类识别

| 规则 | 触发条件 | 结论 |
| ------ | ---------- | ------ |
| 六大类总述 | 财运低迷、破财贫弱财滞 | 大体分六类：比劫夺财、身弱不担财、财库虚空、财星受制、食伤不通、官杀耗财；须先找准根源，盲目旺财越调越漏 |
| ①比劫夺财 | 比劫过旺、无官杀制衡且无食伤流通 | 为人仗义大方、人缘好，但赚钱不难存钱极难：借钱不还、合伙被坑、人情开销大、意外破财 |
| ②身弱不担财 | 日主身弱、财星偏旺（财多身弱） | "富屋贫人"：机遇多门路多却担不住，胆小错失、能力跟不上，偶得大钱也易耗散，求财辛苦难积累 |
| ③财库虚空 | 命局无四库、财星无库，或四库逢冲破损漏气 | 钱来去匆匆、留不住余钱，收入再多花销同步变多，无固定积蓄与长久资产；最对症补财库 |
| ④财星受制 | 财星被严重克制/冲刑/耗泄（印旺克食伤、官杀旺耗财、五行冲克财根） | 财源受损、财气不通：求财门路少、收入渠道窄，赚钱极费力、易遇瓶颈，常因家人长辈工作压力耗财 |
| ⑤食伤不通 | 食伤偏弱、被克或闭塞 | 老实本分、踏实上班却收入平平：无输出优势、缺特长口才技术、思维固化，不是守不住财而是没有稳定生财渠道 |
| ⑥官杀耗财 | 官杀过旺、无印星转化 | 工作忙碌压力巨大、付出多回报少，钱多耗在应酬人情责任开销上，事业易遇小人阻截财路；化解方向为以印转化官杀 |

## 参考命例

三个"旺财综合案例"均为**描述型**（本体系不给出完整四柱，只有五行/十神配置描述，不可复现）：

- **案例一 · 比劫旺无库、常年漏财**：日主身强 + 比劫叠旺无官杀制衡 + 财库虚空（描述型）→ 补财库 + 纯银饰品规整比劫 + 四方聚财阵 + 行为修心，坚持四个月，意外破财消失、年末有积蓄。
- **案例二 · 身弱不担财、禄神受损**：日主身弱 + 财星偏旺 + 禄神逢冲（描述型）→ 禄神旺财法 + 翡翠玉饰固本 + 九宫纳财阵 + 作息养生，调理半年，升职加薪、正财稳步提升。
- **案例三 · 外债滞留、讨债无果**：财气流通阻滞 + 比劫耗财严重（描述型）→ 讨债阵法（分批布阵）+ 补财库 + 黄水晶聚财守库 + 行为规避，一至两月内多笔外债陆续回笼。

> 三案均无四柱，仅可作"配置—症状—方案—效果"的规则佐证，不可当真实排盘复现。

## 判断标准

断对了会看到：
- 命主反馈"赚多少花多少、年终没积蓄"，且能对上比劫夺财/财库虚空的特征；
- 说出漏财场景（借钱不还、合伙被坑、人情开销、意外破财），命主点头；
- 一次针对性化解后，最直观的是**意外破财减少、开始有固定结余**；
- 禄神受损者调理后职场趋稳、薪资有动静。

断错了会看到：
- 命主说"我只是收入低，没有漏财"，却硬套补财库/比劫夺财；
- 明明身弱不担财，却只补财库/只摆招财摆件，越调越破财；
- 财旺身弱者一味补财，反而更耗（该制比劫而非补财）。

## 什么时候不该用它

- **补财库不是一次到位**：它是一次修补、长期稳固，须持续养护（每月清洁整理、戒大手大脚），当一次性操作或频繁补库（气场杂乱）都会失效。
- **须先稳场防"虚不受补"**：自身气场虚弱、心态浮躁者直接补财库无效（财库补上了却承载不住），要先筑基稳场、固本养运再补。
- **讨债阵仅限合法借贷**：赌博、投机、非法往来、无凭证的无理纠纷绝对不可用，否则扰乱自身气场、结人际怨；且对"确无偿还能力"者效果微弱。
- **财旺不可一味补财须制比劫**：身弱财旺时财为忌，正解是比劫制财（壮大自身、守财掌控），不可再补财助忌。
- **无八字 / 未判喜忌者**：本技能依赖八字与喜忌判定，判错喜忌则旺财操作反成伤害；只有公历生日问"我财运如何"而无从排盘时，无法启动。
- **覆盖不到的问题**：能不能当官、事业格局层次、贵贱高低——**不含事业格局层次判断**；纯问投资理财选股、创业赛道选择也不属此断法。
- **效力边界**：本体系自承重大定数祸福只能减灾、避灾、转灾，不能凭空造财、彻底改命；号称"补财库一夜暴富"者皆骗局。
