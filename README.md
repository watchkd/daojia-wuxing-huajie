# 道家五行调理助手 · Daojia Wuxing Tiaoli

依据四柱八字与完整命书，做专业五行推演，确定喜忌并结合大运流年，输出**可执行**的五行调理建议函。

> 适配 Trae 等支持技能包的开发环境，可直接安装使用。

---

## 一、这个技能包能做什么

- **两种输入模式**
  - `<模式A>` 直接传入 **四柱八字 + 性别 + 出生年份 + 起运年岁**，内部完成排盘校验与喜忌推演；
  - `<模式B>` 直接丢入 **一份命书文件 / 命书正文**（优先推荐），自动抽取八字、五行占比、喜忌、神煞与大运，直接复用命书已判结论发布报告。
- **专业推演，而非"缺啥补啥"**
  - 五行调理报告必须依据**准确、专业的五行推演**，在**确定喜忌、并结合大运流年配合**的前提下出具，方达最佳效果；
  - 不凭"某五行缺位即需补齐"或"干支数量多少"草率判断，须综合月令、通根、透干、藏干、生扶克泄、合冲刑会。
- **可执行、不制造恐慌**
  - 交付定位是**一份干净的调理建议函**（方位 / 色彩 / 饮食 / 行为），不含工程分析话术；
  - 神煞仅在其"贴身 + 多煞叠加 + 得令 + 无吉神制衡"成立时提示，不作过度渲染。

## 二、安装

将 `daojia-wuxing-huajie` 目录放入环境的能力/技能目录（如：Trae 技能目录 `.trae` / 全局技能目录）。默认建议：

```
技能包/
└─ daojia-wuxing-huajie/
   ├─ SKILL.md
   ├─ 测试_行为级复核.md
   └─ references/
      ├─ 输入与异常处理约定.md
      ├─ 五行判定检查表.md
      ├─ 神煞查法表.md
      └─ 调理规则映射表.md
```

## 三、使用示例

**输入 A · 四柱**
> "我给八字：甲子 乙亥 庚戌 癸未，男，1984 年生，8 岁起运，帮我出一份五行调理建议。"

**输入 B · 命书**
> "给这位命主的命书做一份五行调理建议报告。"（随后附上命书文件）

**推荐流程**
1. 优先使用完整精确的命书（模式 B，最优）；
2. 没有命书的用户，可先用**排盘软件排出准确的四柱八字**，再输入（模式 A）出具报告。

## 四、设计原则

- **输入 → 证据 → 判断 → 方向**：每条建议可追溯，不只有结论清单；
- **喜忌与大运流年配合**：不只谈论"命局喜忌"，还结合当前大运/流年校准当年宜忌力度；
- **冲突留白**：当不同判定导向相反方案（如从格边缘、通关五行本身为忌神）时，如实保留权衡，不伪装精确唯一解；
- **资料声明**：本技能全部内容与规则整理，**资料源自网络公开信息与各类道家典籍**，供学习交流与传统文化研究参考。

---

## 五、注意事项

- 五行调理属传统文化体系的**辅助建议**，用于起居、心态与环境调整，**不替代**医疗诊断、财务规划或重大职业与人际决策；
- 不宣称"调理后必有改善 / 改命 / 消灾 / 暴富"；守"减灾避灾转灾"边界。
