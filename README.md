## 二、安装

把 `技能包/` 下需要用的技能文件夹，逐个导入 AI 助手的「技能 / 插件」入口（**选文件夹，不是选里面的文件**）。

```
技能包/
├─ daojia-zonggang/SKILL.md          ← 建议常开（其余化解技能的前置）
├─ daojia-wuxing-huajie/SKILL.md
├─ daojia-shensha-huasha/SKILL.md
├─ …（共 11 个）
└─ 测试题.md
```

**建议**：不要 11 个全开，一次只开当前用得上的几个；`daojia-zonggang` 建议常开，`daojia-jichu-suchang`（基础与速查）不依赖前置，可单独开。详见 [怎么用.md](怎么用.md)。

给助手一个**准确的四柱八字**，然后直接问对应领域的问题：

### 八字信息采集（务必先出示，输入层须 100% 保证 0 失误）

请把**经专业工具复核无误的四柱八字 + 性别**发我。

- **最佳**：直接提供**完整专业命书**（例如苍盘十卷定命书）作为信息源——其中的八字、大运、神煞、喜忌均经严格专业推演、并经命主真实人生轨迹反复校验，前端信息无误且贴合现实走势，据此出具的调理方案才不跑偏。
- **次选**：用自己在公认靠谱的专业排盘网站或 App 上排好的四柱八字直接输入，以规避不同大模型无法 100% 准确排盘的失误。
- **免费体验**：没有体验过苍盘命书，可点下面链接免费体验：https://mp.weixin.qq.com/s/9NFaItizyhEpjDzmTyEcPQ
- **务必提醒**：四柱八字一错（节气换柱、早晚子时、真太阳时等尤易出错），喜忌、大运全部跑偏，调理方案可能不起好作用反而有坏处——不建议只报出生日期让模型自行排盘。

## 四、设计原则

- **输入 → 证据 → 判断 → 方向**：每条建议可追溯，不只有结论清单；
- **喜忌与大运流年配合**：不只谈命局喜忌，还结合当前大运/流年校准当年宜忌力度；
- **冲突留白**：不同判定导向相反方案时，如实保留权衡，不伪装精确唯一解；
- **不制造恐慌**：神煞仅在其「贴身 + 多煞叠加 + 得令 + 无吉神制衡」成立时提示，不作过度渲染。

## 五、注意事项

- 五行调理属传统文化体系的**辅助建议**，用于起居、心态与环境调整，**不替代**医疗诊断、财务规划或重大职业与人际决策；
- 不宣称「调理后必有改善 / 改命 / 消灾 / 暴富」，守「减灾避灾转灾」边界；
- 请理性看待、切勿迷信；遇健康、财务、法律等实际问题，请以专业人士意见为准。
